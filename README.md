Credit Scoring Data Extraction:
Tiered system combining traditional OCR, deterministic checks, and fallback using multimodal LLMs.
Serverless system (Azure Durable Functions, Azure Document Intelligence, Foundry). Deployed on Azure as per hackathon requirements.

Note: All data is synthetic and obfuscated.
